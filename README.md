# claude-code-usage-quota setup

This project enables the [claude-code-usage-quota](https://github.com/anantraghunath/claude-code-usage-quota-mod) plugin for Claude Code.

The setup lives in `.claude/settings.json`. It adds the `claude-code-usage-quota-mod` marketplace and enables `claude-code-usage-quota@claude-code-usage-quota-mod`. When you open this folder and trust it, Claude Code offers to install the plugin.

To install it by hand instead:

```
/plugin marketplace add anantraghunath/claude-code-usage-quota-mod
/plugin install claude-code-usage-quota@claude-code-usage-quota-mod
```
